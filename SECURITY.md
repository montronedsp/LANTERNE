# Security

Report security problems in Lanterne to the maintainer, MontroneDSP.

There is no bounty programme. There is no disclosure deadline written here;
reports are answered as fast as one maintainer can answer them.

This build is local-only. The tree has not been published, and no binary is
distributed from this repository. The embedded browser view renders ROM
content that the plugin loads from its own `ROMs/` folder; treat an
untrusted ROM the way you would treat any untrusted page.

Once the repository is public, reports can also go through
https://github.com/montronedsp/LANTERNE.
