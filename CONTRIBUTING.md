# Contributing

Lanterne is a local project. Patches are welcome later against `main` on
https://github.com/montronedsp/LANTERNE once the repository is public.

## Host code

Contributions to the C++ host, CMake files, and scripts are accepted under
**AGPL-3.0-or-later**, the same licence as the rest of the project. By
sending a contribution you place it under that licence.

## ROMs

A ROM contributed into `ROMs/` is accepted under **MIT** unless the author
states otherwise in the contribution. ROMs stay separate works from the
host; see `docs/ROM_AUTHORS.md`.

## Style

Do not reformat the whole tree in a contribution. Keep changes readable
against the file you touched. Follow `.editorconfig`.

## What is not on the table

No plugin parameters, no audio processing, no measurement features, no
second browser backend, no CI badges. See `ROADMAP.md`.
